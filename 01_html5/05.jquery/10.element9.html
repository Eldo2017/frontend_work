** each() 메소드

배열의 모든 인덱스에 순차적으로 접근하려고 할 때
객체가 가진 모든 속성에 순차적으로 접근하려고 할 때
사용하는 for in문과 유사하게 수행되는 메소드 

        1) $.each(객체 | 배열, 함수([매개변수, ...]){
                순차적으로 접근할때마다 실행할 내용;
            })

        2) 객체 | 배열.each(함수([매개변수, ...]) {
                순차적으로 접근할때마다 실행할 내용;
            })

            > 객체가 들어오면, 
              첫번째 매개변수에는 순차적으로 접근할 때마다 객체의 속성명(키)이 담긴다

              두번째 매개변수에는 해당 속성값이 담긴다

              
            > 배열이 들어왔을 경우,
              첫번째 매개변수에는 순차적으로 접근할 때마다 객체의 인덱스 번호가 담긴다

              두번째 매개변수에는 해당 인덱스의 값이 담긴다
