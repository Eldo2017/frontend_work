* jquery?

- 기존의 자바스크립트 언어론 구현하기 복잡했던 구문들을 간소화시키기 위해 '존 레식'에 의해 고안된 체제 - javascript 기반 라이브러리
 즉, 자바스크립트 언어로 유용한 함수나 내용들을 이미 정의되어있는 모음집
- 복잡한 자바스크립트 구문보다 짧고 쉽게 개발할 수 있다
1) jquery의 장점 - DOM 요소와 관련된 스크립트를 보다 쉽게 구현할 수 있다
- Ajax(비동기식 통신), 이벤트 처리 등등을 폭넓게 지원한다
- jquery와 관련된 확장형 플러그인에 오픈 api 등등을 지원한다
 (chart, slide 등등)

* jquery의 작성 방법

jquery 구문으로 DOM 요소를 다루는 구문을 기본적으로 작성하므로
문서 상 요소들이 모두 만들어지고 나서 실행되야 한다

- 순수 자바스크립트 / jquery 비교 

        window.onload
        window.onload = function() {
            실행할 내용;
        }

        해당 문서 내 요소들이 모두 로드되고 뿐만 아니라
        연동되어 있는 외부 문서들도 모두 로드가 된 후에 실행이 된다.
        그리고 여러번 작성 시 맨 마지막 것으로 덮어쓰기된다.

        즉시실행함수 life
        ([변수] = function([매개변수, ...]){
            실행내용;
        })(인자, ...)

        브라우저가 해당 줄을 읽는 순간 즉시 실행이 된다.
        html이나 이미지같은 외부리소스 로드와 상관없이 실행된다.
        그 자바스크립트 파일이 파싱되는 중간에 즉시 실행.
        그리고 몇 번이든 사용이 가능하다.

        jquery
        그 자바스크립트 파일이 파싱된 후 DOM트리가 완성되면 실행.
        html이나 이미지같은 외부리소스 로드와 상관없이 실행된다.
        그리고 몇 번이든 사용이 가능하다.

- jquery 구문 작성 
        1) jquery(document).ready(function() {
            실행할 내용;
        });

        2) $(document).ready(function() {
            실행할 내용;
        });

        3) $(function() {
            실행할 내용;
        });

        4) $(() => {
            실행할 내용;
        }); // 화살표 함수는 es6 이상 버전에서 사용할 수 있다.
