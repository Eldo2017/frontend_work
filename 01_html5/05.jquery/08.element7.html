Content 관련 메소드

* html(['문구']) 메소드 : innerHtml 속성과 관련된 메소드

선택된 요소의 content 영역의 값을 리턴하거나 변경한다
>> $('선택자').html() : 선택이 된 요소의 content 영역의 값을 반환해준다(html 태그도 포함) >> $('선택자').html('문구') : 선택이 된 요소의 content 영역의 값을 해당 문구로 바꾼다(html 태그가 있다면 태그로 인식한다)

* text(['문구']) 메소드 : innerText 속성과 관련이 된 메소드

선택된 요소이 content 영역 값을 리턴하거나 변경한다
>> $('선택자').text() : 선택된 요소의 content 영역을 반환한다(html 태그는 포함하지 않는다. 오로지 텍스트로만)
>> $('선택자').text('선택자') : 선택된 요소의 content 영역을 전달한 값으로 변경한다(html 태그는 포함하지 않는다. 오로지 텍스트로만)
