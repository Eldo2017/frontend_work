객체

* 객체 선언 및 사용

- 객체는 중괄호{}를 이용해 생성하고,
 중괄호 안에 이 객체에 필요한 속성을 정의한다
- 속성명.속성값의 형태로 정의한다(key:value)
 속성값으로는 모든 자료형의 값을 담을 수 있다. 

        변수 = {
            속성명 : 속성값, 
            속성명 : 속성값, 
            속성명 : 속성값, 
            속성명 : 속성값, 
            ...
        }

* 객체 생성 시 특이케이스도 있다(속성명 제시시 반드시 문자열로 해야 되는 경우)

* 객체에서의 반복문

객체가 가지고 있는 모든 속성들에 순차적으로 접근하려고 하면 반복문을 사용할 수 있다
근데, 단순한 for문으론 절대 불가능하다. 향상된 for문만 사용이 가능하다.
