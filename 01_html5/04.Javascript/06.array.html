배열

- 변수 선언 시 별도의 자료형 필요없다
- 어떤 자료형 값들이든 구별없이 저장된다
- 크기 제약이 없다
- 존재하지 않는 인덱스를 참조해도 오류가 없다(undefined 반환)

* 배열 선언하기

* 배열 관련 메소드

1) 배열.indexOf(찾으려 하는 요소) : 배열에서 해당 요소가 있는 index 반환

2) 배열.concat(배열, 배열, 배열, ...) : 배열 여러개를 결합하려고 할 때 사용

- 원본 배열에 영향을 끼치지 않는다

3) 배열.reverse() : 배열에 담긴 값이 거꾸로 출력된다

- 원본 배열에 영향을 끼친다

4) 배열.sort() : 배열 안에 담긴 값들을 오름차순으로 정렬한다

- 원본 배열에 영향을 끼친다 (reverse와 동일)

5) 배열.push(추가 요소) : 배열의 맨뒤에 요소 추가 후 배열 크기를 반환시킨다

6) 배열.pop() : 배열의 맨뒤의 요소 제거 후 제거된 요소를 반환시킨다

7) 배열.unshift(추가 요소) : 배열의 맨앞에 요소 추가 후 배열 크기를 반환시킨다

8) 배열.shift() : 배열의 맨앞의 요소 제거 후 제거된 요소를 반환시킨다

9) 배열.slice(시작인덱스, 끝인덱스) : 배열의 시작 인덱스부터 끝 인덱스 전까지 추출한다

10) 배열.splice(시작인덱스, 제거수[,추가할 값])) : 배열의 요소를 추출해 제거 및 추가, 제거한 요소를 반환한다

11) 배열.toString() / 배열.join([구분자]) : 배열의 각 인덱스에 담긴 값을 하나의 '문자열'로 합쳐서 반환한다
