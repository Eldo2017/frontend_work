자바스크립트의 기본

1. 자바스크립트가 무엇인가?

프로그램 동작을 사용자의 요구에 맞게 수행되도록 하는 용도로 사용한다
빠르게 배우고 짧은 소스코드로 상호작용이 되게 고안되었다

2. 자바스크립트

웹 브라우저에서만 많이 사용되는 "인터프린터 방식"의 스크립트 언어다
- 인터프린터 방식 : 코드를 한줄씩 읽어가며 바로 실행하는 방식 (실시간으로 텍스트를 분석하여 실행이 된다)
=> 코드에 문법오류가 있다면 실행 시점에서 바로 알 수가 있다

3. 장점 및 단점

* 장점

  • 컴파일 과정이 완전히 필요가 없어서 인터프린터 코드를 한줄씩 읽어가며 실행되므로 수행속도가 빠르다
  • 코드 작성이 간단해서 초보자가 접하기 쉬운 언어다(단순한 구조, 원칙)
    ex) 접근 제한자의 개념이 없고, 변수 선언시 자료형을 따로 정하지 않아도 된다

* 단점

  • html 소스 코드에서 작성되면 외부에 공개돼서, 보안에 취약하다

4. 자바스크립트의 사용법

  1. inline(인라인) : 태그 내 간단한 소스코드를 작성해 실행되게 한다
  2. internal(내부) : html 문서 내에 소스코드를 작성해 실행되게 한다
  3. external(외부) : 별도의 .js 파일로 소스코드를 작성해 실행되게 한다

1) inline 방식

태그 내에 간단한 소스코드를 작성해 실행되게 한다 [표현법]
<태그 on이벤트명 = "해당 요소에 해당 이벤트 발생 시 실행할 코드">

2) internal 방식

현재 html 문서 내에 script 태그 안에 소스코드를 작성해 실행되게 한다
script 태그는 head나 body 태그에 모두 작성할 수 있다.



3) external 방식

별도의 .js 파일로 소스코드를 작성해 실행되게 한다
script 태그는 head나 body 태그에 모두 작성할 수 있다.
