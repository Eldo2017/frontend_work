자바스크립트에서의 데이터 입출력

        * window : 자바스크립트 내장 객체로 브라우저 창이 열릴때마다 하나씩 만들어진다

                   브라우저 창 내에 존재하는 모든 요소들의 최상위 객체이다 => 생략할 수 있다

        * document : 웹 문서마다 하나씩 만들어지는 객체(html 문서에 대한 정보를 가지고 있다)

1. 데이터 출력용 구문

1) [window.]alert("알림창에 출력할 내용");
2) [window.]console.log("콘솔에 출력할 내용");
3) document.write("화면상에 출력할 내용");
4) 선택한 요소.innerHTML | innerText = "요소에 출력할 내용";

1. document.write("화면상에 출력할 내용");



2. 선택한 요소.innerHTML | INNERText = "요소에 출력할 내용";

자바스크립트에서 어떤 요소(element) 안의 값(content)을 가지고 오거나
변경하려고 할 때 innerHTML, innerText란 속성에 접근하여 이용하라


2. 데이터를 입력받는 구문 (변수에 기록도 할 수 있다)

1) 변수 = [window.]confirm("질문내용");
2) 변수 = [window.]prompt("질문내용");
3) 변수 = 선택한 요소.속성(id, className, innerHTML, innerText ...);
4) 변수 = 선택한 input 요소.value;

1) 변수 = [window.]confirm("질문내용");

confirm 호출 시 "질문내용"과 "확인, 취소" 두 개의 버튼이 있는 알림창이 나타난다 "확인"을 클릭할 시 true, "취소"를 클릭할 시 false가 들어온다

2) 변수 = [window.]prompt("질문내용");

prompt 호출 시 "질문내용"과 입력할 수 있는 "텍스트 상자"와 "확인/취소" 버튼이 있는 알림창이 나타난다
"확인" 클릭 시 텍스트 상자에 있는 입력한 값이 문자열로 반환, "취소" 클릭 시 NULL값을 반환한다.


3) 변수 = 선택한 요소.속성(id, className, innerHTML, innerText ...);

4) 변수 = 선택한 input 요소.value;
