함수

선언 방법


  1. 선언적인 함수(Function Declaration) : function 키워드, 함수명
  2. 익명 함수(Function Expression) : 변수에 익명 함수를 대입한다
  3. 화살표 함수(Arrow Function) : 익명 함수를 간단히 작성한다(es6에 추가)
  4. 즉시 실행함수 life(Immediately Invoked Function Expression)
    • 선언과 호출
    • 변수의 캡슐화 처리가 유용하다

* 선언적 함수

        function 함수명([매개변수, ...]) {
            해당 함수 호출시 실행할 코드;
            [return 결과값;]
        }

* 익명 함수

        변수 | 속성 = function([매개변수, ...]) {
            해당 함수 호출시 실행할 코드;
            [return 결과값;]
        }

        - 특정 변수나 속성에 대입되는 함수 제시에 주로 사용이 된다

* 화살표 함수

        - 본문에 리턴만 있다면

          변수 = ([매개변수, 매개변수,...]) => 리턴값

        - 본문이 여러줄이라면
          
        변수 = ([매개변수, 매개변수,...]) => {
            해당 함수 호출시 실행할 코드;
            [return 결과값;]
          }

* 즉시 실행 함수

        - 정의하면서 즉시 실행이 되는 함수

        - 단 한번만 호출이 된다
          
        ([변수] = function([매개변수,매개변수,...]) {
            해당 함수 호출시 실행할 코드;
            [return 결과값;]
        }

함수의 매개변수


* 매개변수 관련 arguments

함수 호출 시 전달되는 값은 내부적으로 arguments 형식에 담긴다


* 매개변수에 this 관련 전달하기

- this : 현재 이벤트가 발생한 요소 객체다

화살표 함수의 매개변수 및 리턴

* 매개변수 지정 방식

        - 매개변수가 없는 경우 : () => return값;
        - 매개변수가 하나라면 : 매개변수명 => return값; (소괄호 생략 가능하다)
        - 매개변수가 하나 이상이면 : (x,y) => return값; (소괄호 필수!)

* 함수 body 지정 방식

        - single line block이라면
            x => {return 값;}
            x => 값 {return 키워드와 중괄호 생략 O}
        - multi line block이라면
            x => {
                실행구문;
                return값;
            }
